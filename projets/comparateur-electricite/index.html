En production

Comparateur d'abonnements d'électricité

Simule plus de 140 offres d'électricité sur votre vraie consommation Linky, directement dans le navigateur, sans partage de données.

Voir le site Voir le code source

Le comparateur rejoue votre propre historique de consommation Linky sur les offres d'électricité du marché, pour savoir combien vous auriez payé sur un an avec chacune. Un prix réel, contrairement à une comparaison avec un foyer type.

Ce qu'il fait

  • Simule plus de 140 offres de plus de 30 fournisseurs directement depuis un export de consommation.
  • Applique les vraies couleurs des jours Tempo, les jours EJP et les plages d'heures creuses de chaque contrat.
  • Utilise les prix spot EPEX réels pour les offres indexées sur le marché de gros.
  • Classe les résultats par coût annuel, abonnement proratisé au jour près.
  • Le tout à 100 % en local pour protéger la vie privée.

Les détails techniques

Le projet a démarré en 2023 en vanilla JS. Des articles dans la presse informatique lui ont rapidement donné de la visibilité. Au départ, je le développais en solitaire. Il réunit aujourd’hui 20 contributeurs et compte plus de 140 étoiles sur GitHub.

Ce changement d’échelle implique aussi un travail de gestion de projet. Il faut guider les contributeurs, construire un cadre pour faciliter les revues de code et apprendre à dire non à un contributeur enthousiaste. Il faut aussi mettre en place des tests pour prévenir les régressions, vérifier le bon fonctionnement du comparateur et faciliter la collaboration.

2026 a été une année charnière. L’IA a fait un bond en avant, et le projet aussi. La prise en charge de plus de 140 offres aux modes de calcul variés m’a forcé à reprendre le code pour automatiser les imports.

Pour ajouter une offre, je pars de la grille publiée par le fournisseur. Je m’appuie sur l’IA pour écrire le code qui en extrait les prix et les tests qui vérifient leur lecture. Lors des mises à jour suivantes, ce code relit la grille selon les mêmes règles. Si un montant est ambigu, l’import s’arrête pour la grille concernée. Les tests rejouent aussi un historique de consommation pour repérer les écarts avec les simulations de référence. Je peux ainsi superviser les changements avant de les valider.

Fun fact : sur une grille, le montant TTC de l’abonnement Heures Creuses était imprimé dans le tableau voisin. Une lecture automatique risquait de reprendre le prix de la ligne précédente. Depuis sa mise à jour, le harness reproduit ce défaut de mise en page et vérifie que l’import s’arrête si les montants ne concordent pas.
