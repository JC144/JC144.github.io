Electricity plan comparison tool

Compare more than 140 electricity plans using readings from your Linky smart meter. The calculations run in your browser and your data stays there.

Visit the website View source code

The tool uses your own Linky smart meter readings to calculate what you would have paid over a year on each electricity plan. The comparison reflects your household’s actual usage.

What it does

  • Compares more than 140 plans from over 30 suppliers using your exported meter readings.
  • Accounts for each day’s actual Tempo colour, EJP peak days and each contract’s off-peak hours.
  • Uses actual EPEX spot prices for plans tied to the wholesale electricity market.
  • Ranks plans by annual cost, prorating the standing charge by the day.
  • Runs entirely in your browser to keep your meter readings private.

Technical details

I started the project in 2023 using vanilla JavaScript. Coverage in the tech press soon helped it reach a wider audience. What began as a solo project now has 20 contributors and more than 140 stars on GitHub.

As the project grew, managing contributions became part of my work. That means guiding contributors, setting up a code review process and learning when to say no to an enthusiastic contributor. It also means putting tests in place to catch regressions, check that the tool works as expected and make it easier to work together.

2026 was a turning point. AI took a leap forward, and so did the project. Supporting more than 140 plans, each with its own pricing rules, pushed me to rework the code so I could automate tariff imports.

To add a plan, I start with the tariff sheet published by the supplier. I use AI to help write the code that extracts the prices and the tests that check it reads them correctly. On subsequent updates, the code reads the sheet using the same rules. If a price is ambiguous, the import stops for that sheet. The tests also rerun a simulation on historical meter readings and compare the results with a reference run. That lets me review the changes before approving them.

Fun fact: On one tariff sheet, the standing charge for the off-peak plan, including tax, was printed in the neighbouring table. The importer could have picked up the price from the row above. The updated test harness reproduces that layout error and checks that the import stops if the amounts disagree.
